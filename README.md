# vue-filtro-productos

Catalogo con filtro reactivo en Vue 3 (Composition API + script setup + props/computed).

> Proyecto de portafolio de Luis Felipe Zuniga Leon. Desarrollado con asistencia de IA
> (generacion de codigo, revision y documentacion); el codigo fue revisado y probado manualmente.
> No declara clientes, metricas ni resultados no verificables.

## Stack

- Vue 3
- Vite
- Composition API

## Como ejecutar

```bash
npm install
npm run dev
```

## Estructura

```
src/components/ProductFilter.vue  # filtro reactivo
src/App.vue                        # datos de ejemplo
src/main.js
```
